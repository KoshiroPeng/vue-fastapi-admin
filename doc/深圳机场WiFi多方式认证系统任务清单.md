## 当前执行策略

1. 优先实现 FastAPI 认证前置网关；
2. 第二阶段实现运维管理台；
3. 当前无真实 NCE，所有开发和自动化测试使用 NCE Mock；
4. 外部服务通过统一客户端接口隔离，后续接入真实 NCE 时不得修改上层业务契约；
5. 旅客端 Portal H5 延后，当前只实现其所需后端领域能力和稳定 API 契约。
